BuyNest is a modern e-commerce website focused on selling watches and clocks. The main
aim of this project is to create a smooth and convenient online shopping experience for users.
Customers can easily browse through different categories of watches and clocks, view
product details, add items to their cart, and place orders securely. The website also includes
features like user registration, login, product search and filtering, order history, and a
responsive design that works well on all devices.

For admins, BuyNest provides an easy-to-use dashboard to add, update, or remove products,
manage user orders, and keep track of inventory. The website is built using the MERN
stack—MongoDB for the database, Express.js and Node.js for the backend, and React.js for
the frontend. This technology stack helps make the website fast, interactive, and scalable.

Overall, this project provides a complete e-commerce solution and helps in understanding
real-world web development, user interface design, and backend management.
